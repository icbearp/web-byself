# 阿里云大陆版上线清单

## 推荐基础设施

- 地域：主要用户所在区域；浙江用户优先杭州或上海。
- ECS：包年包月，2 核 4 GB，Ubuntu 24.04 LTS，ESSD 40–60 GB，公网 IPv4，固定带宽约 5 Mbps。
- RDS MySQL：与 ECS 同地域、同 VPC，MySQL 8.0；初期使用基础版即可，正式业务量上升后再升级高可用版。
- RDS 不开放公网地址，只允许 ECS 私网连接；3306 不加入公网安全组。
- 域名：`otafuku.top` 完成实名认证后，按阿里云备案流程提交浙江个人主体 ICP 备案。

## 上线前必须确认

个人主体只适合与备案主体和备案内容一致的非经营性网站。当前需求包含用户注册、保存金融账单、管理员查看用户提交记录；如果网站用于有偿销售、导流或商业服务，应先向阿里云备案审核和浙江省通信管理部门确认主体类型，不要在备案未确认前直接上线这套功能。

未备案期间只允许做服务器内部测试，不能用未备案域名对外提供网站服务。

## 阿里云运行环境变量

复制 `.env.example` 为服务器上的 `.env`，真实值只放服务器或阿里云密钥管理中，不要提交 GitHub：

- `APP_PUBLIC_URL`：正式域名，例如 `https://otafuku.top`
- `DATABASE_URL`：RDS MySQL 私网连接字符串
- `SESSION_SECRET`：随机生成的长密钥
- `ADMIN_EMAIL`：接收用户账单提醒的管理员邮箱
- `SMTP_*`：注册验证码、账单提醒邮件服务配置
- `PUBLIC_STORAGE_MODE=aliyun`

## 用户流程

1. 访客先正常使用计算器，不强制注册。
2. 点击“保存账单”时弹出服务提示：保存内容、管理员可见范围、保存期限、删除方式和隐私说明。
3. 用户同意后注册或登录，再保存账单。
4. 用户可以查看、修改和删除自己的账单。
5. 管理员只能查看必要的账单摘要、用户标识和提交时间，并收到新账单提醒；默认不发送完整身份证、银行卡或其他无关敏感信息。

## 部署顺序

1. 购买 ECS、完成 ICP 备案。
2. 我将 Cloudflare 专用 Worker 入口与阿里云 Node 入口隔离，保持共享页面和计算逻辑不变。
3. 接入 MySQL 用户、会话、账单和管理员通知表。
4. 在服务器配置 Nginx、HTTPS、进程守护和自动备份。
5. 先用临时测试域名验证，再切换 `otafuku.top`。
